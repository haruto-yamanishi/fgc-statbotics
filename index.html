How predictions and EPA work

Pre-match scores start from past score levels and country EPA, then update with this year's results, recent trends, and event progress. Because each year has a different game, projections before the first match are provisional. A match prediction uses only results available before that match.

FGC EPA estimates a team's contribution from ranking-match alliance scores; it is not an individual score. In 2026, main EPA covers non-endgame points and endgame EPA covers climbing and related points. All predictions and EPA values are unofficial estimates.

In 2026, the ranking score is the average ranking-match score after dropping one lowest score. A red-card match cannot be dropped. The projected ranking score adds upcoming projected scores in order; it is an estimate, not official RP.
