# 予測モデルの最適化

`npm run optimize` は FIRST Global 公開 API から 2022～2025 年の結果を取得し、試合前予測を時系列で再計算します。ダウンロード結果は OS の一時ディレクトリにキャッシュします。新しい公式データを取得したい場合は `npm run optimize -- --refresh` を使います。`npm run optimize -- --write` は評価条件を満たした係数だけを `src/model-config.js` に書き込みます。

2024 年のランキング戦 360 試合で係数を選びました。勝率は引き分けを除く 350 試合の対数損失、得点は赤・青アライアンスを合わせた平均絶対誤差（MAE）で評価します。係数を選んだ後、使っていない 2025 年のランキング戦 362 試合で確認しました。2022 年の API に試合結果がないため、2024 年の予測に使う前年情報は主に 2023 年です。

| 大会 | 設定 | 勝率の対数損失 ↓ | 得点 MAE ↓ | 勝敗的中率 |
| --- | --- | ---: | ---: | ---: |
| 2024（調整） | 従来 | 0.635 | 25.24 点 | 66.0% |
| 2024（調整） | 最適化後 | 0.574 | 22.71 点 | 70.3% |
| 2025（未使用の確認データ） | 従来 | 0.643 | 18.22 点 | 63.8% |
| 2025（未使用の確認データ） | 最適化後 | 0.625 | 17.92 点 | 65.7% |

更新した主な係数は、EPA の正則化 `6 → 16`、過去実績の縮小率 `0.7 → 0.5`、勝率変換のスケール `2.5 → 1.25`、試合後の評価更新率 `0.14 → 0.32`、評価値が予測得点に与える係数 `0.65 → 1.4` です。大会進行度の係数 `0.7` は維持されました。

`--write` は 2024 年の対数損失と得点 MAE が両方改善し、2025 年で対数損失の悪化が 0.01 以下、得点 MAE の悪化が 0.5 点以下の場合だけ変更します。2025 年の結果は係数の探索に使っていません。大会ごとにゲームが変わるため、2026 年の精度を保証するものではありません。2026 年の公式ランキング戦が増えたら、別の未使用データとして改めて検証できます。

探索はスクリプトに定義した有限の候補値を順番に比較する方式です。全ての係数の組み合わせを総当たりした大域的な最適解ではありません。
