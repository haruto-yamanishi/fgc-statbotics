# 予測モデルの最適化

`npm run optimize` は FIRST Global 公開 API の 2022～2025 年データを読み、各ランキング戦の直前に分かっていた結果だけで予測を再計算します。同時刻の試合結果も互いの予測に使いません。2022 年の API に試合結果がないため、2023 年の初戦には前年の得点情報がありません。

```bash
npm run optimize
npm run optimize -- --trials=500 --seed=2026
npm run optimize -- --refresh
npm run optimize -- --write
# 2026 年の勝敗が決まった公式戦が 30 試合以上になったら診断可能
npm run optimize -- --validation-year=2026 --refresh
```

探索は再現できる乱数で候補を作り、上位候補の周辺をさらに調べます。標準設定は探索 160 回で約 250 種類の係数を比較します。取得した API データは OS の一時ディレクトリに保存します。`--refresh` は公式データを取り直し、`--data-dir=...` は保存先を指定します。`--write` は下記の採用条件を通過した場合だけ `src/model-config.js` を更新します。

2023・2024 年の試合で係数を選びます。勝敗の的中率、対数損失、Brier スコア、予測得点の平均絶対誤差（MAE）を計算し、対数損失を中心にした目的関数で候補を並べます。引き分けは勝敗の集計から除き、勝率がちょうど 50% の試合は「予測なし」として的中に数えません。得点予測がまだ作れない試合は得点 MAE から除きます。候補は今年のアライアンス得点による評価更新や、チーム評価の減衰量も含みます。

2025 年は採用判定にだけ使います。似た候補で検証結果を繰り返し選ばないよう、今年の得点を取り込む強さごとに開発データで最良だった候補だけを確認します。現行設定より検証年の正解数が 3 試合以上増え、対数損失・Brier スコア・得点 MAE が全て悪化しないことが必要です。2025 年の結果は以前の開発でも確認済みなので、完全な未使用テストとは呼びません。`--validation-year=2026` にすると 2023～2025 年で係数を選び、2026 年で判定します。2026 年に勝敗が決まった公式ランキング戦が 30 試合あれば診断できますが、係数の採用には 60 試合以上必要です。

2026 年 10 月時点の標準探索では、次の結果でした。2023 年の「予測なし」29 試合も的中率の分母に含めています。

| 大会 | 設定 | 勝敗的中 | 対数損失 ↓ | 得点 MAE ↓ |
| --- | --- | ---: | ---: | ---: |
| 2023（係数選定） | 現行 | 193/306（63.1%） | 0.596 | 18.23 点 |
| 2023（係数選定） | 最良候補 | 208/306（68.0%） | 0.545 | 16.65 点 |
| 2024（係数選定） | 現行 | 246/350（70.3%） | 0.574 | 22.71 点 |
| 2024（係数選定） | 最良候補 | 269/350（76.9%） | 0.515 | 21.96 点 |
| 2025（採用判定） | 現行 | 209/318（65.7%） | 0.625 | 17.92 点 |
| 2025（採用判定） | 同じ最良候補 | 205/318（64.5%） | 0.681 | 17.72 点 |

最良候補は 2025 年の勝敗と確率予測が悪化したため、採用されませんでした。**公開画面で使う係数は現行のまま**です。2024 年だけで良く見える変更を 2026 年の予測へ自動反映しないための採用条件です。FGC は毎年ゲームが変わるため、FRC Statbotics の的中率をそのまま目標値として保証することもできません。

2026 年 10 月 8 日の[公式 API](https://api.first.global/v1?year=2026&excludeMatchDetails=true)ではランキング戦 340 試合中 39 試合が終了し、勝敗の決まった 38 試合で現行モデルは 23 試合を的中しました。対数損失は 0.617、予測得点 MAE は 65.31 点です。過去年で選んだ候補のうち得点 MAE が最良のものは 63.01 点でしたが、的中数は同じ 23 試合で対数損失は 0.623 に悪化しました。**今回は係数を変更していません。** 公開画面の得点水準とチーム評価は、すでに今年の終了試合を自動で取り込んで更新されます。
