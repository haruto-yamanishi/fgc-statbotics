# FGC Stats

FIRST Global Challenge の公開結果 API を使った、対戦表・試合予測・チーム分析の非公式ダッシュボードです。7言語で表示できます。

## できること

- 公開済み対戦表から、選択チームの次の試合と全試合の予定を表示
- 赤・青アライアンスの予測得点（Estimated Points）と予測勝率、選択チーム基準の勝利・敗北予想を表示
- 2026 年の予定試合後に選択チームが到達する予測ランキングスコアを表示
- 2026 年のチーム別ランキングに、全残り試合を反映した最終予測ランキングスコアとその並び替えを表示
- 終了した試合の実得点、WIN / LOSE、試合前予測、的中・不的中を表示
- 試合前の勝者予想から直近30公式戦の予想的中率を自動集計（引き分け・勝率50:50は分母から除外、全期間の精度はモデル検証に保持）
- 選択チームの勝敗、公式順位の前年比、総合・試合本体・終盤それぞれの FGC EPA ランキングを表示
- チーム検索、試合検索、シーズン切り替え
- 60 秒ごとに公式データを再取得
- 日本語、英語、スペイン語、フランス語、ポルトガル語、簡体字中国語、韓国語の表示切り替え

このサイトは [山西遥斗](https://x.com/haruroute1107)（[FRC Team 9494 Hanabi](https://9494hanabi.com/)）が制作しました。[チーム公式X](https://x.com/FRC_Hanabi) もご覧ください。FIRST Global および Statbotics の公式サイトではありません。

2026 年の FIRST Global Challenge では、FRC のような勝敗に応じた RP ではなく、[公式ゲームマニュアル](https://docs.google.com/document/d/11uHfXaXqNHy9q4LvUZ5AduTErb12A0mZC6fgkDYeBf8/view) 6.3 節の**ランキングスコア**で順位を決めます。各チームのランキング戦得点から最低の1試合を除いた平均で、レッドカードの試合は除外できません。予測ランキングスコアは、公開済みの結果とこれからの試合の予測得点を時系列で組み合わせた非公式の推定値です。初戦だけの場合はその得点を表示し、サロゲート・ノーショーは集計しません。

2026 年の公式順位は大会開始前には空です。その間も対戦表から参加チームを作成し、2025 年と 2024 年の国別 EPA を基に暫定予測を計算します。過去年のチーム ID は変わるため、国コードで対応付けます。

国名や 3 文字コードを検索欄に入力すると、最初に一致したチームへ即座に切り替わります。候補が複数ある場合は隣のリストから選べます。

初戦前の予測得点は過去 2 年の得点スケールを使う暫定値です。過去のランキング戦を試合順に 4 分割し、各区間の得点水準から大会進行度の補正係数を作ります。ゲームが毎年異なるため、その傾向は 70% の強さで適用します。今年の結果が公開されると、進行度の影響を除いた今年の平均得点と直近 24 アライアンスの得点水準を取り込みます。予測結果の検証は試合順に行い、同時刻の試合結果は互いの予測に使いません。

公式集計前の Test Match / Practice Match は、結果一覧・EPA・今年の得点水準から除外します。

FGC EPA はランキング戦のアライアンス得点からチームの寄与を加法モデルで推定します。2026 年の終盤得点は[公式ゲームマニュアル](https://docs.google.com/document/d/11uHfXaXqNHy9q4LvUZ5AduTErb12A0mZC6fgkDYeBf8/view)の登坂倍率による加点、パートナークライム、協力ボーナスから求めます。本体得点は公式得点から終盤得点を引いた値です。詳細データがない場合、内訳 EPA は表示しません。予測と EPA は参考値で、FIRST Global や Statbotics の公式指標ではありません。

モデル係数は過去試合の時系列検証で調整できます。手順と調整前後の結果は[モデル最適化の記録](docs/model-optimization.md)にまとめています。

## 2026年の勝敗予測モデル（Opponent-Aware v2）

2026年の**勝敗確率**は、Wildfire Suppression Unit の得点差と相手の強さを反映する新しい逐次更新モデルを使用します。チームの国別過去年EPAを事前情報とし、2026年にすでに終了したランキング戦のWildfire得点差と勝敗からチーム評価を更新します。得点差が小さい試合では更新を抑え、同じ開始予定時刻の試合はお互いの結果を予測に使用しません。Endgameは今回の最適化では勝敗確率への独立した追加効果を確認できなかったため、勝率モデルの重みはゼロにしています（EPAの内訳計算や得点予測は従来通りです）。

採用判断時の2026年ランキング戦90試合中、勝敗決着89試合について、**現行モデル55/89（61.8%）に対して新モデル62/89（69.7%）**、Log Lossは0.626から0.615になりました。これは試合より前のデータのみを使った**時系列バックテスト**であり、過去に配信した予測をその時点で保存した記録ではありません。新しい結果で数値は更新されます。過去の結果を使ってモデル選択しているため、今後も同じ的中率を維持できる保証はありません。

2023〜2025年の表示には以前と同じモデルを使用します。2026年の予測得点・EPA・予想ランキングスコアは以前の計算のままです。

## ローカルで起動

依存パッケージやビルドは不要です。

```bash
npm test
npm run serve
```

[http://localhost:8080](http://localhost:8080) を開いてください。 `index.html` を `file://` で直接開くとブラウザーの制限で API を取得できません。

## データ

[FIRST Global 公開結果 API](https://api.first.global/v1?year=2026&excludeMatchDetails=false) からブラウザーが直接読み込みます。

## 公開

GitHub Pages のワークフローを同梱しています。GitHub の **Settings → Pages → Source: GitHub Actions** を有効にすると `main` への push で公開できます。
